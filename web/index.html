What you get

          
Editor smarts, not just a text box

          
Every part of the playground is wired into the IDE — the real engine, the file you have open, and the structure of your own JSON.

        


        

          

            split editor
            
Live preview, per file

            
JSON opens in a split editor, like Markdown: source on the left, playground on the right. Switch files and you get that file's own playground. Recompute is debounced and bounded against runaway expressions.

            
orders[status = "shipped"].id

          


          

            lexer + language
            
Syntax highlighting

            
A dedicated JSONata language with its own lexer colors paths, string and number literals, operators, and the $ functions as you type.

            
payload.items[price > 10] ~> $sort()

          


          

            annotator
            
Errors, underlined in place

            
Your expression is compiled by the real engine. A syntax error is underlined exactly where it happens — not buried in a console somewhere below.

            
$sum(items.price

          


          

            completion
            
Field names that know your data

            
After a . the plugin evaluates the path under your cursor against the bound JSON and suggests the real field names — so completion works even through predicates and function calls.

            
orders.items.

          


          

            completion
            
Built-ins with signatures

            
Type $ and the catalog of JSONata functions appears — each with its signature, so you pick the right one without a trip to the docs.

            
$map · $filter · $reduce · $sort · $distinct

          


          

            parameter info
            
Parameter hints

            
Inside a function call, the signature pops up with the current argument highlighted — so you always know which parameter you're filling in.

            
$substring(str, start, length)

1
Open a JSON file. It opens in the split editor — preview hidden by default, nothing in your way.

          
2
Reveal the playground with the Editor / Split / Preview toggle, or the floating Open JSONata Playground button.

          
3
Write an expression. Ctrl+Space for fields and functions; Ctrl+P for a signature. The result tracks every keystroke.
